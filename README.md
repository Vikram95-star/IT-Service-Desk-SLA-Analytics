# IT Service Desk SLA Analytics

## 📌 Project Overview
A SQL-based analytics project designed to analyze IT service desk incidents, SLA compliance, ticket resolution performance, and operational support trends.

The project uses SQL to transform raw support ticket data into meaningful business insights for IT management.

## 🎯 Business Objectives
- Track total, open, and closed support tickets
- Measure SLA compliance and SLA breaches
- Analyze ticket volume by department, category, and priority
- Evaluate technician performance
- Identify departments with the highest SLA breaches
- Analyze ticket resolution times
- Identify high-priority and unresolved incidents

## 🛠️ Technologies Used
- MySQL
- SQL
- MySQL Workbench

## 📊 Key Analysis
- Ticket volume analysis
- Priority analysis
- SLA breach analysis
- SLA compliance percentage
- Average resolution time
- Department performance
- Category analysis
- Technician performance
- Open ticket monitoring
- SLA target comparison using JOIN
- SLA status analysis using CTE
- Technician and department ranking using Window Functions

## 📈 Key Results
- Total Tickets: **10**
- Closed Tickets: **9**
- Open Tickets: **1**
- SLA Breaches: **4**
- SLA Compliance: **55.56%**
- Average Resolution Time: **21.11 hours**

## 💡 Business Insights
- **Sales** had the highest number of SLA breaches.
- **Low-priority tickets** had a 100% SLA breach rate.
- **Arun and Rahul** had the highest number of SLA breaches among technicians.
- One **High-priority open ticket** requires attention.
- Finance and IT recorded no SLA breaches among closed tickets.
